# ADR 003 — SQLite + Drizzle ORM + Append-Only Event Log
---
status: accepted
date: 2026-06-02
---

## Context
Local-first app needs a zero-setup, zero-dependency database that works offline and can sync to Postgres in v2.

## Decision
SQLite via better-sqlite3. Drizzle ORM for TypeScript-native schema and migrations. Append-only events table as the platform's shared event log.

## Alternatives Considered
- **Postgres (local):** Requires a running server process. Violates zero-setup goal.
- **IndexedDB:** Browser-only. Doesn't work in Electron main process.
- **PrismaORM:** Heavier, slower cold starts, less control over raw SQL when needed.

## Consequences
- Single `.db` file — easy to back up, copy, and debug
- Drizzle migrations are TypeScript — type-safe schema evolution
- Append-only event log: every domain emits events here — powers observability and future ElectricSQL sync
- v2 sync: ElectricSQL replicates SQLite → Postgres with no schema changes

## UUID Enforcement
All primary keys are UUID v4 generated by `generateId()` from `@creare/shared`. Auto-increment integers are forbidden.
